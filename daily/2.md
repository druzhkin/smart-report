# Day 2 — Tuesday 2026-04-26 (continued same Claude Code session)

## Что сделано

1. **`smart_report/sources/valyu.py`** — Valyu client v0 (170 lines):
   - `ValyuClient(api_key, sdk_factory)` — async wrapper around Valyu
     Python SDK 2.9.4. SDK is sync; we wrap calls in `asyncio.to_thread`.
   - `ValyuResult` dataclass — minimal projection of SDK SearchResult
     (url, title, content, source, price, relevance_score,
     publication_date, data_type, metadata).
   - `.search(query, search_type, category, max_results, fast_mode,
     included_sources, excluded_sources, relevance_threshold)` —
     primary surface. Defaults to `search_type="all", fast_mode=True`
     (live-API-compatible, see A3 below).
   - Retry shim: 3 attempts, exponential backoff (1s/2s/4s), retry on
     5xx + ConnectionError + Timeout, NO retry on 4xx (auth/payment/
     rate-limit). Mirrors Step 3.1 OpenRouter shim.
   - Failures wrapped as `ValyuSearchError` so callers handle one
     error type from this module.
   - `_to_valyu_result(sdk_result)` — defensive adapter that
     stringifies structured content + tolerates missing optional fields.

2. **`smart_report/sources/__init__.py`** — package init exposing
   `ValyuClient`, `ValyuResult`, `ValyuSearchError`.

3. **Tests `tests/test_valyu_client.py`** (12 mocks + 1 live):
   - 5 success-path / parameter-passthrough tests
   - 4 retry-shim tests (5xx / ConnectionError / 4xx / 429 / max
     retries exhausted)
   - 2 adapter tests (structured content stringification, missing
     optionals)
   - 1 `@pytest.mark.live` smoke against arXiv ($0.001 spend) —
     PASSED on real Valyu API.

4. **`pyproject.toml`** — registered `live` pytest marker; added
   `not live` to default `addopts` so live tests skip in CI.

5. **Live finding logged** in `BLOCKERS.md` A3: Valyu API rejects
   `fast_mode=True` + `search_type="proprietary"` together. Brief
   tension between "fast everywhere" and "Valyu primary for
   proprietary corpora" resolved by defaulting to
   `search_type="all"` + `fast_mode=True` and documenting that Day 3
   routing must override to `("proprietary", fast=False)` when
   targeting value-add datasets.

## Findings worth noting

- **Valyu Python SDK 2.9.4 surface is clean**: 6 client methods,
  Pydantic response types, sync `requests` underneath. Async wrap via
  `asyncio.to_thread` is the right shape for our pipeline.
- **Per-call price for arXiv smoke was $0.001** (CPM=$1) — exactly
  what `VALYU_CAPABILITY_MAP.md` predicted.
- **The `is_tool_call=False` parameter**: SDK has this — set it so
  Valyu doesn't treat our calls as agent-tool-call (which has
  different rate-limit semantics per their docs surface).
